# Site Nexus Office

Site vitrine statique, sans framework ni dépendance à installer.

## Prévisualisation locale

Ouvrir simplement `index.html` dans un navigateur.

## Publication

Le site pourra être publié gratuitement avec GitHub Pages une fois le dossier choisi comme source de publication ou via un workflow dédié.

## Téléchargements

Les boutons Windows, macOS et Linux restent volontairement désactivés tant que les installateurs ne sont pas construits, testés et publiés dans GitHub Releases. Ne pas ajouter de liens fictifs.
