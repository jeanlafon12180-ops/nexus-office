# Contributing

Thanks for your interest in Nexus Office.

## Before contributing

- Open an issue to discuss substantial changes.
- Keep pull requests focused.
- Include build and test notes.
- Do not add third-party source or assets without recording their origin and license.

## Development expectations

- Use C++17 for the initial desktop shell.
- Keep UI code separate from document-engine integration.
- Prefer clear names and small, reviewable changes.
- Update documentation when architecture or supported platforms change.

## Project status

Nexus Office is an early prototype. APIs, folder structure, and product scope may change.
